# Modul 1 — Dasar Pemrograman C++

Repository ini berisi contoh program C++ yang dibuat sebagai pendamping **Modul 1 — Code Blocks IDE & Pengenalan Bahasa C++ (Bagian Pertama)** pada praktikum Struktur Data

---

## Isi 

### 01 — Hello World

`01_hello_world.cpp`

Program paling sederhana untuk mengenalkan struktur dasar program C++ dan penggunaan `cout` untuk menampilkan teks.

### 02 — Struktur Program

`02_struktur_program.cpp`

Menunjukkan bagian-bagian dasar sebuah program C++, seperti `#include`, `main()`, statement, dan `return`.

### 03 — Identifier

`03_identifier.cpp`

Mengenalkan identifier, yaitu nama yang digunakan untuk variabel, konstanta, fungsi, atau objek lain dalam program. Contoh juga menunjukkan bahwa C++ bersifat **case-sensitive**.

### 04 — Tipe Data

`04_tipe_data.cpp`

Mengenalkan beberapa tipe data dasar seperti `char`, `int`, `long`, `float`, dan `double`.

### 05 — Variabel

`05_variabel.cpp`

Menunjukkan cara mendeklarasikan, memberikan nilai awal, dan mengubah nilai sebuah variabel.

### 06 — Konstanta

`06_konstanta.cpp`

Mengenalkan konstanta menggunakan `const`, yaitu nilai yang tidak dapat diubah selama program berjalan.

### 07 — Output dengan `cout`

`07_output_cout.cpp`

Menunjukkan cara menampilkan teks, karakter, dan nilai variabel ke layar menggunakan `cout`.

### 08 — Escape Sequence

`08_escape_sequence.cpp`

Mengenalkan escape sequence seperti `\n` untuk baris baru, `\t` untuk tabulasi, `\"` untuk tanda kutip, dan `\\` untuk backslash.

### 09 — Input dengan `cin`

`09_input_cin.cpp`

Menunjukkan cara menerima masukan dari keyboard menggunakan `cin` dan menyimpannya ke dalam variabel.

### 10 — Input dengan `getchar()`

`10_input_getchar.cpp`

Mengenalkan `getchar()` untuk membaca satu karakter dari input standar.

---

## Operator

### 11 — Operator Aritmatika

`11_operator_aritmatika.cpp`

Contoh penggunaan operator `+`, `-`, `*`, `/`, dan `%` untuk melakukan operasi aritmatika.

### 12 — Operator Assignment

`12_operator_assignment.cpp`

Mengenalkan operator assignment seperti `=`, `+=`, `-=`, `*=`, `/=`, dan `%=`.

### 13 — Operator Perbandingan & Logika

`13_operator_logika_dan_perbandingan.cpp`

Menunjukkan operator perbandingan seperti `>`, `<`, `>=`, `<=`, `==`, `!=` serta operator logika `&&`, `||`, dan `!`.

### 14 — Type Casting

`14_operator_casting.cpp`

Menunjukkan bagaimana suatu nilai dapat dikonversi ke tipe data lain, terutama untuk menghindari hasil operasi yang tidak sesuai akibat perbedaan tipe data.

### 15 — `sizeof`

`15_operator_sizeof.cpp`

Mengenalkan operator `sizeof` untuk mengetahui ukuran sebuah tipe data atau variabel dalam byte.

### 16 — Increment & Decrement

`16_increment_decrement.cpp`

Mengenalkan operator `++` dan `--`, termasuk perbedaan **pre-increment** dan **post-increment**.

### 17 — Type Modifier

`17_type_modifier.cpp`

Mengenalkan pemodifikasi tipe seperti `unsigned` dan `long`.

---

## Kondisional

### 18 — `if`

`18_if.cpp`

Menunjukkan bagaimana program mengambil keputusan berdasarkan suatu kondisi menggunakan `if`.

### 19 — `if-else`

`19_if_else.cpp`

Menunjukkan dua kemungkinan keputusan: ketika kondisi bernilai benar dan ketika kondisi bernilai salah.

### 20 — Operator Ternary

`20_operator_ternary.cpp`

Mengenalkan bentuk singkat dari `if-else` menggunakan operator kondisional `?:`.

### 21 — `switch-case`

`21_switch.cpp`

Menunjukkan pengambilan keputusan dengan beberapa pilihan menggunakan `switch`, `case`, dan `default`.

---

## Perulangan

### 22 — Perulangan `for`

`22_perulangan_for.cpp`

Menunjukkan cara menjalankan sebuah blok program berulang kali menggunakan `for`.

### 23 — Perulangan `while`

`23_perulangan_while.cpp`

Menunjukkan perulangan yang terus berjalan selama kondisi yang diberikan masih terpenuhi.

### 24 — Perulangan `do-while`

`24_perulangan_do_while.cpp`

Mengenalkan `do-while`. Berbeda dengan `while`, blok program pada `do-while` akan dijalankan setidaknya satu kali sebelum kondisi diperiksa.

---

## Struktur Data Dasar

### 25 — `struct`

`25_struct.cpp`

Mengenalkan `struct` sebagai tipe data bentukan yang dapat mengelompokkan beberapa variabel dengan tipe berbeda ke dalam satu kesatuan.

### 26 — Array & `struct`

`26_array_struct.cpp`

Menunjukkan penggunaan `struct` yang dikombinasikan dengan array untuk menyimpan beberapa data dengan struktur yang sama.

### 27 — Function

`27_function.cpp`

Mengenalkan function untuk memisahkan bagian program menjadi fungsi yang dapat dipanggil dari program utama. Contoh menggunakan function untuk melakukan konversi Celsius ke Fahrenheit.
